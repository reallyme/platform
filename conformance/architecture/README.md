# Architecture Conformance

Architecture conformance proves that applications, contracts, kits, and hosts
retain their assigned responsibilities. Executable enforcement lives in
`scripts/policy/verify-workspace-standards.sh` and
`scripts/policy/verify-contract-boundaries.sh`; the normative model is
`docs/concepts/architecture.md`.

New cross-layer rules must be added to an executable policy or compile-time
test before this index is extended.
